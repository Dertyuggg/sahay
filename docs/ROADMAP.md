# SAHAY-24 Product Roadmap

## Phase 1: MVP (Hackathon 24-Hours)
- [x] Basic UI scaffolding and routing.
- [x] Core Accessibility Utility implementation (CSS variables, Voice hooks).
- [x] High-contrast, large-hit-area design system.
- [x] Mock backend endpoints for fetching balances and executing dummy transfers.

## Phase 2: Beta Integration (Next 30 Days)
- **Real Backend:** Swap Express mock endpoints for a robust backend (e.g., Spring Boot or Next.js API with PostgreSQL).
- **Authentication:** Implement biometric and voice-based secure authentication (FIDO2 standards).
- **Expanded A11y Testing:** Conduct live user testing sessions with elderly and motor-impaired communities.

## Phase 3: Scaling & Smart Features (Month 2-6)
- **AI Voice Assistant:** Full integration of an LLM-powered natural language assistant for conversational banking.
- **Fraud Detection:** Behavior-based anomaly detection to protect vulnerable users from scams.
- **Multilingual Support:** Localized text and voice options for low-literacy users across different regions.
